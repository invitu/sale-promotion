Adds an option on discount rewards on specific products to discount each
eligible product unit at most once, for instance one discount per drink
served in a customer's own bottle, whatever the number of bottles.

This module only adds the configuration; the computation is provided by
the sales channel modules (e.g. ``pos_loyalty_reward_unit_limit``).

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

On a discount reward on specific products, with an amount or a
percentage, check *Limit to Eligible Units*. Each claim then discounts
one unit and costs the reward's required points.
